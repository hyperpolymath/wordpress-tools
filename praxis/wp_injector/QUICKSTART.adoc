== WP Injector Quick Start Guide

Get started with the WP Praxis Symbolic Injector in 5 minutes.

=== Prerequisites

* Rust toolchain (for building)
* WordPress installation
* MySQL/MariaDB access
* Valid wp-config.php

=== Build

[source,bash]
----
cd wp_injector
cargo build --release
----

Binary location: `+target/release/wp_injector+`

=== Your First Injection

==== 1. Create a Simple Manifest

Create `+my-workflow.toml+`:

[source,toml]
----
[metadata]
name = "My First Workflow"
version = "1.0.0"

[[symbols]]
name = "update_site_title"
type = "option"
rollback = "snapshot"

[symbols.parameters]
option_name = "blogname"
option_value = "My WP Praxis Site"
----

==== 2. Validate the Manifest

[source,bash]
----
./target/release/wp_injector validate --manifest my-workflow.toml
----

Expected output:

....
✓ Manifest validation successful!
....

==== 3. Dry Run (Test Without Changes)

[source,bash]
----
./target/release/wp_injector inject \
  --manifest my-workflow.toml \
  --wp-root /var/www/html \
  --dry-run
----

==== 4. Execute the Injection

[source,bash]
----
./target/release/wp_injector inject \
  --manifest my-workflow.toml \
  --wp-root /var/www/html
----

Expected output:

....
✓ Injection completed successfully!
  ID: inj_1732234567
  Symbols injected: 1
  Timestamp: 2025-11-22T12:34:56Z
....

==== 5. Check Status

[source,bash]
----
./target/release/wp_injector status --wp-root /var/www/html
----

==== 6. Rollback (If Needed)

[source,bash]
----
./target/release/wp_injector rollback \
  --last 1 \
  --wp-root /var/www/html
----

[source,bash]
----

  --manifest my-workflow.toml \
  --wp-root /var/www/html
----

[source,bash]
----
./target/release/wp_injector inject \
  --manifest my-workflow.toml \
  --wp-root /var/www/html \
  --verbose
----

[source,bash]
----
./target/release/wp_injector inject \
  --manifest my-workflow.toml \
  --wp-root /var/www/html \
  --log-file injection.log
----

=== Common Patterns

==== Multiple Options

[source,toml]
----
[[symbols]]
name = "site_settings"
type = "option"
rollback = "snapshot"

[symbols.parameters]
option_name = "blogname"
option_value = "My Site"

[[symbols]]
name = "tagline"
type = "option"
rollback = "snapshot"

[symbols.parameters]
option_name = "blogdescription"
option_value = "My tagline"
----

==== Custom Post Type with Taxonomy

[source,yaml]
----
symbols:
  - name: my_cpt
    type: post_type
    rollback: snapshot
    parameters:
      post_type: portfolio
      label: Portfolio

  - name: my_tax
    type: taxonomy
    depends_on: [my_cpt]
    rollback: snapshot
    parameters:
      taxonomy: portfolio_cat
      label: Categories
----

==== Dependency Chain

[source,toml]
----
[[symbols]]
name = "first"
type = "option"
[symbols.parameters]
option_name = "step_1"
option_value = "done"

[[symbols]]
name = "second"
type = "option"
depends_on = ["first"]
[symbols.parameters]
option_name = "step_2"
option_value = "done"

[[symbols]]
name = "third"
type = "option"
depends_on = ["second"]
[symbols.parameters]
option_name = "step_3"
option_value = "done"
----

=== Troubleshooting

==== Can’t Connect to Database

[arabic]
. Check wp-config.php exists at `+{wp-root}/wp-config.php+`
. Verify database credentials
. Ensure MySQL is running: `+systemctl status mysql+`
. Test connection: `+mysql -u username -p database_name+`

==== Validation Fails

Run with verbose mode to see details:

[source,bash]
----
./target/release/wp_injector validate \
  --manifest my-workflow.toml \
  --verbose
----

==== Permission Denied

Ensure you have: - Read access to wp-config.php - Write access to
`+wp-content/.wp-praxis/+` - Database permissions for INSERT/UPDATE

=== Best Practices

[arabic]
. *Always validate first*: Run `+validate+` before `+inject+`
. *Use dry run*: Test with `+--dry-run+` flag
. *Version your manifests*: Use git to track manifest changes
. *Descriptive names*: Use clear symbol names
. *Enable rollback*: Use `+rollback = "snapshot"+` for safety
. *Check dependencies*: Ensure dependency chains are correct
. *Test rollback*: Verify rollback works in development
